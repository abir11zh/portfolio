# Abir Zahraoui — AI & Data Science Portfolio

A responsive bilingual portfolio built with HTML, CSS, and vanilla JavaScript. Its warm ivory, blush, and burgundy palette follows the supplied moodboard, with an editorial serif, optional dark theme, and layouts from desktop through mobile.

## Preview locally

Open `index.html` in a browser, or run a static server from this directory:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

1. Create or open the intended repository (suggested name: `abir-ai-portfolio`).
2. Commit and push these website files to `main`.
3. Open **Settings → Pages**.
4. Choose deployment from a branch, select `main` and `/ (root)`, then save.
5. Wait for the Pages build and open the published URL to verify it.

Asset paths are relative for repository-subpath hosting. No backend or API credentials are required. A sitemap is omitted until the published URL is known.

## Content and assets

- Portrait: `assets/images/abir-portrait.png`
- CV download: `assets/documents/Abir_Zahraoui_CV.pdf`
- Contact configuration: `js/config.js`
- Project descriptions and details: `js/main.js`

The project gallery and detail dialogs use the supplied project-preview images, optimized as WebP in `assets/images/projects/`. The CyberDetect and CareerSVM notes clarify that dashboard figures shown in those previews are not treated as validated model benchmarks. The five project source links are connected individually to the supplied DataPilot AI, ChurnIQ, CyberDetect AI, CareerSVM AI, and Smart Traffic Controller repositories. CareerSVM AI replaces AgriSmart to match the supplied five-project repository list. ChurnIQ benchmark metrics and the recall-focused recommendation come from its repository README. The About section offers the supplied English and French photo CVs as separate downloads.

## Features

- English/French language toggle and saved preference.
- Light/dark theme toggle and saved preference.
- Responsive navigation, category filters, and accessible project detail dialogs.
- Direct email, phone, LinkedIn, GitHub, and CV links.
- Reduced-motion support, keyboard focus states, and SEO/Open Graph metadata.
